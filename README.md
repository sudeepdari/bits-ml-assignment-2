# Adult Income Classifier Lab

## a. Problem Statement

Build and compare five classification models that predict whether an adult's
annual income is above $50,000 using demographic and employment attributes.
This is an educational exercise. The dataset includes sensitive demographic
attributes and reflects historical patterns; predictions must not be used for
employment, lending, or other consequential decisions.

## b. Dataset Description

The dataset is the UCI Adult (Census Income) dataset, originally extracted from
1994 US Census data. It contains 14 input features (six numeric and eight
categorical) and the binary target `income` (`<=50K` or `>50K`). The supplied
files provide 32,561 training rows in `census-income/adult.data` and 16,281
test rows in `census-income/adult.test`. The test file's metadata line and
trailing punctuation in its labels are handled by the training script. `?`
values are treated as missing and imputed within each model pipeline.

Dataset documentation: [UCI Adult Dataset](https://archive.ics.uci.edu/dataset/2/adult)

## d. Models Used and Test Results

All models use the same supplied train/test split. Preprocessing is fitted only
on the training data and saved with each classifier. Precision, Recall, and F1
use `>50K` as the positive class. AUC uses probability estimates, or decision
scores for the linear SVM.

| ML Model Name | Accuracy | AUC | Precision | Recall | F1 | MCC |
|---|---:|---:|---:|---:|---:|---:|
| Logistic Regression | 0.8507 | 0.9038 | 0.7282 | 0.5871 | 0.6501 | 0.5618 |
| Decision Tree | 0.8249 | 0.7758 | 0.6439 | 0.5788 | 0.6096 | 0.4983 |
| K-Nearest Neighbors | 0.8332 | 0.8676 | 0.6639 | 0.5952 | 0.6276 | 0.5219 |
| Gaussian Naive Bayes | 0.5511 | 0.7611 | 0.3378 | 0.9376 | 0.4967 | 0.3300 |
| Support Vector Machine (linear) | 0.8519 | 0.9032 | 0.7376 | 0.5788 | 0.6486 | 0.5630 |

### Model Observations

| ML Model Name | Observation about model performance |
|---|---|
| Logistic Regression | Best F1 (0.6501) and AUC (0.9038), with strong overall accuracy. It gives the strongest balance on the selected F1/AUC comparison. |
| Decision Tree | Lowest AUC (0.7758) and MCC (0.4983) among these runs. Its test performance is below the linear models and KNN. |
| K-Nearest Neighbors | AUC of 0.8676 and F1 of 0.6276 are competitive, but below Logistic Regression and the linear SVM on this test split. |
| Gaussian Naive Bayes | Highest recall (0.9376), but low precision (0.3378) and accuracy (0.5511), indicating many false positive predictions for `>50K`. |
| Support Vector Machine | Highest accuracy (0.8519) and MCC (0.5630), and AUC close to Logistic Regression. Its F1 (0.6486) is just below Logistic Regression. |
| Overall Winner for this dataset | Logistic Regression by F1 and AUC; the linear SVM is a close alternative and leads slightly on accuracy and MCC. |

## Run Locally

From the project directory, create and activate the virtual environment, then
install dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt --index-url https://pypi.org/simple
```

Train the models, evaluate them on the supplied test split, and generate the
cleaned `test_data.csv`, `metrics.csv`, and saved model pipelines:

```powershell
python train_models.py
```

Start the app:

```powershell
streamlit run app.py
```

The dashboard evaluates all five saved pipelines on the bundled test data by
default. Upload another labeled CSV to evaluate it instead. It must include all
14 feature columns and the `income` target column; the app does not retrain any
model.
